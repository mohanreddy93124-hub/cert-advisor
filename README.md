# Cert Advisor

Free, open-source website that recommends security and compliance certifications (ISO 27001, SOC 2, PCI DSS and more) based on your region, data, budget and deadline.

## Run it
Open `index.html` in a browser. No install, no server, no database.

## Deploy free
GitHub repo > Settings > Pages > Deploy from branch `main` / root.

## Improve the data
Certification data is in the `CERTS` array in `index.html`. Every number is a **placeholder estimate** until `verified: true` and `sources` links are added. Please send pull requests with official sources.
